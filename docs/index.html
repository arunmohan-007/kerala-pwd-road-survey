      How the counts are calculated

      Points recorded by RMMS Cell, RMMS Cell 2, or RMMS Cell 3 are excluded from this and future reports.

      Roads in list counts register entries. Listed roads covered counts entries with at least one Start point and one End point matched unambiguously to the same road. Start and end counts refer to individual points.

      New roads counts distinct manually entered road identities absent from the register. Spelling variations can affect this count. Ambiguous matches and incomplete identities are flagged for review.
